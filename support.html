SUPPORT

Get connected.
Stay connected.

Agent Remote has two parts: a free Mac app that runs your Claude Code and Codex sessions, and the iPhone app that controls them. Most questions come down to pairing the two and keeping the Mac reachable. Email smatt989@aol.com if this page does not solve it; include your iPhone app version (Settings → About) and Mac app version (menu bar → About).

01 / SETUP

Pair in under a minute.

What you need
A Mac on macOS 13.5 or later, an iPhone on iOS 17 or later, and a Claude Code or Codex account. Provider usage and billing stay with your provider.
1. Install the Mac app
Open the Agent Remote DMG, drag the app to Applications, and open it. Use its Claude/Codex setup buttons if the command-line tools are missing or need sign-in.
2. Show a pairing code
In the Mac app, click Show pairing code. The QR code is single-use and expires after five minutes; treat it like a password while it is on screen.
3. Scan from the iPhone
In the iPhone app, choose Pair this iPhone → Scan QR code, confirm the Mac’s name, and tap Pair Mac. Your Mac appears in Chats whenever it is awake, online, and running Agent Remote.
Optional
Enable Start at login on the Mac so remote access survives a restart. Enable Terminal Access to share sessions you start in Terminal with your phone.

02 / TROUBLESHOOTING

When something doesn’t connect.

“Mac unavailable”
The Mac must be awake, online, and running Agent Remote (menu bar shows Relay: connected). Sleep, a closed lid, or quitting the app all end remote access. Check System Settings → Energy to prevent sleep while plugged in.
Pairing code rejected
Codes expire after five minutes and work once. Click Show pairing code again for a fresh one.
Session won’t accept messages
A conversation owned by another client (for example a Claude session running in a separate terminal) is read-only until that client exits. Exit it, then resume from Agent Remote.
No reply notifications on the lock screen
In-app alerts work as soon as you turn notifications on. Background alerts need Apple Push configured on the Mac; the Notifications screen tells you if it is still waiting for that setup.
Camera or microphone not working
Check iPhone Settings → Agent Remote and allow Camera (pairing), Microphone and Speech Recognition (dictation).
Remove a phone
On the Mac, open Agent Remote → Devices and revoke the phone, or from the project folder run npm run devices then node desktop/src/admin.mjs revoke DEVICE_ID.

03 / GOOD TO KNOW

A paired phone is a key to your Mac.

Sessions created from Agent Remote run with broad access on your Mac and without the usual agent approval prompts. Pair only devices you trust, keep your phone locked, and revoke a device you lose. See how your connection works and the privacy policy for what is and isn’t visible to the relay.
